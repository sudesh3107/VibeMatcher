# VibeMatcher

A responsive entertainment recommendation prototype built with Bootstrap and plain JavaScript.

## What is included
- Predefined questions to help pick interests
- Recommendation cards with reasons and matching factors
- Genre-based catalog view
- Platform availability and pricing details
- Login and contact-style sections
- Recent comments area for watched titles

## Run locally
Open the workspace folder in a browser, or serve the files with a simple static server:

```bash
cd /workspaces/VibeMatcher
python3 -m http.server 8000
```

Then visit http://localhost:8000.
